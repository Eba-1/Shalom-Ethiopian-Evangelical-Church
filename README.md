# Church Community Website Concept

Responsive church homepage concept built with React, TypeScript, Vinext, and Tailwind CSS.

## Requirements

- Node.js 20 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Then open the local address printed in your terminal, normally `http://localhost:3000` or `http://localhost:5173`.

## Production build

```bash
npm run build
npm start
```

## Main files to edit

- `app/page.tsx` — homepage content and sections
- `app/globals.css` — colors, typography, layout, and responsive design
- `app/layout.tsx` — page title and metadata
- `public/` — place your church images and other public assets here

The colored gallery panels are placeholders. Replace them with approved photographs from the church before publishing.
